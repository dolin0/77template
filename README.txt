77 TEMPLATE STUDIO — 사용 / 무료 배포 안내

1. 폴더 안의 index.html 파일을 두 번 클릭하면 내 컴퓨터 브라우저에서 시험할 수 있습니다.
   (온라인 글꼴 Pretendard는 인터넷 연결이 필요합니다.)
2. 본 페이지는 서버/회원가입이 없는 정적 웹사이트입니다. 사진과 입력 내용은 현재 기기의 브라우저에 저장되며, 기기 또는 사용자 간 동기화되지 않습니다.
3. GitHub Pages로 공개하려면:
   (1) github.com에서 회원가입/로그인
   (2) New repository 클릭 → 저장소 이름 예: 77-template-studio → Public → Create repository
   (3) Add file → Upload files → index.html 및 assets 폴더 안 logo-77.png를 각각 올리세요. 로고 경로는 반드시 assets/logo-77.png입니다.
       더 쉬운 방법: GitHub 사이트의 파일 업로드를 사용해, 폴더 구조가 유지되도록 파일들을 드래그해서 업로드합니다.
   (4) Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save
   (5) 잠시 후 https://사용자이름.github.io/77-template-studio/ 로 접속할 수 있습니다.
   (GitHub의 메뉴 및 배포 절차는 변경될 수 있습니다.)
4. 공개 저장소의 코드는 모두에게 보이므로 비밀번호 등 개인정보를 넣지 마세요. 편집하며 업로드한 사진은 이 앱 코드에 의해 원격 서버에 전송되지 않습니다.
5. 이미지 내보내기는 PNG(무손실), JPG 고화질(품질 94%), JPG 저화질(품질 67%)입니다.
6. 글자는 Pretendard 웹폰트를 CDN에서 불러옵니다. 처음 접속 시 인터넷 연결이 필요하며 CDN에 접근하지 못하면 대체 폰트로 표시됩니다.

참고: 77 로고는 사용자가 제공한 파일에서 배경을 제거한 PNG입니다. 정확한 원본 벡터 파일과는 가장자리 표현이 다를 수 있습니다.
